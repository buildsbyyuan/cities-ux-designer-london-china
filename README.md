# 🏙️ If Cities Had a UX Designer  
### London vs Shanghai Edition

A product thinking case study that treats cities like digital products and explores how everyday urban experiences are shaped by design decisions.

This project compares **London and Shanghai** from the perspective of a **first-time visitor**, focusing on how people experience the city through three everyday systems: **transport, payments, and wayfinding and guidance**.

Rather than evaluating policy or infrastructure performance, the project looks at how these systems feel to use, where friction appears, and how cities communicate with users through signage, apps, and digital tools.

---

## 🎯 Purpose of the Project

The aim of this project is to apply **product and UX design thinking** to real-world urban systems by:

- mapping everyday user journeys for a first-time visitor  
- identifying moments of confusion, friction, and uncertainty  
- comparing how transport, payment, and guidance systems behave across cities  
- understanding how cities communicate information to users  
- proposing a small number of realistic, user-centred design opportunities  

This is **not a policy project** and **not a data-heavy analysis**.  
It is a **PM-style UX case study** focused on system behaviour and user experience.

---

## 👤 User Focus

The primary user considered throughout the project is:

- a **first-time visitor or newcomer**  
- unfamiliar with the city and its systems  
- relying on public transport, signage, and digital tools  

This framing allows the analysis to focus on clarity, confidence, and ease of use.

---

## 🔍 Core User Journeys

The project analyses three core user journeys in both London and Shanghai:

1. **Getting around the city**  
   A first-time visitor travels from their accommodation to a popular area using public transport, moves between nearby locations on foot, and returns later in the day.

2. **Paying for everyday needs**  
   A first-time visitor pays for food and drinks at a casual restaurant or café using the payment methods available in the city.

3. **Finding and navigating attractions**  
   A first-time visitor looks for a major attraction, navigates there using maps, signage, and digital tools, explores the surrounding area, and then finds their way back.

---

## 🧩 Method and Approach

This project uses a **qualitative, comparison-led approach**, drawing on:

- user journey mapping  
- system comparison  
- friction and assumption analysis  
- simple tables and diagrams  

The focus is on **clarity of reasoning and insight**, not technical depth or modelling.
